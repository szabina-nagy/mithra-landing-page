# Mithra Landing Page

A responsive marketing website for Mithra, a self initiated scam prevention product concept.

Mithra originally began as a fully designed mobile app UX case study in Figma. This project extends that concept into a responsive coded landing page, with a focus on accessibility, responsive design and front end interaction.

## Project Overview

Mithra began as a UX case study for a scam prevention mobile app.

The original app concept was fully designed in Figma, including user flows, wireframes, high fidelity screens, reusable components and interaction states.

This landing page was created as a follow up project to bring the Mithra concept into a responsive marketing website and practise the full design to development workflow using HTML, CSS and JavaScript.

The landing page introduces the product, explains its main features and includes an interactive Scam Checker demonstration.

## The Problem

Online scams increasingly use familiar communication channels, urgency and impersonation to pressure people into acting quickly.

Mithra aims to make checking suspicious communication feel simple, calm and approachable, while helping users recognise common warning signs.

## Target Audience

The primary audience is adults aged approximately 35 and above who use everyday digital services but may feel uncertain when they receive suspicious or urgent messages.

The experience was designed to feel clear, reassuring and easy to understand without relying on technical language.

## Scam Checker Demo

The Scam Checker uses simple predefined keyword patterns to simulate message analysis.

Examples of warning signs include:

- Urgency to act
- Suspicious links
- Requests for personal information
- Unexpected payments or prizes

The checker is a front end demonstration only and does not perform real fraud detection.

## Accessibility

Accessibility was considered throughout both the design and implementation.

The project includes:

- Semantic HTML
- Visible form labels
- Keyboard accessible controls
- Visible focus states
- Accessible mobile navigation
- Escape key support
- Focus management within the mobile menu
- Keyboard focus trapped within the open mobile drawer
- `aria-expanded` and `aria-controls` for navigation
- `aria-live` for dynamic Scam Checker results
- Alternative text for meaningful images
- Decorative icons hidden from assistive technology
- Reduced motion support
- Responsive layouts tested at 200 percent browser zoom
- Colour contrast considered throughout the interface

## Responsive Design

The page was tested across a range of viewport sizes, including:

- 320px
- 390px
- 768px
- 1024px
- 1440px

Layouts adapt between mobile, tablet and desktop views.

The hero, Scam Checker, feature cards and educational cards switch to stacked layouts where necessary to maintain readability and avoid cramped content.
